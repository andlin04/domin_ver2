About the CVE database

  • Source: {{ cve_source }} (OSV.dev for packages, NVD for products matched by CPE) — the same sources the infrastructure vulnerability watch uses. Both update continuously as advisories are published.
  • Mode: {{ cve_mode }}. {% if cve_mode == 'own' %}This instance maintains its own database at {{ cve_db }}, re-querying a target older than {{ cve_ttl }} day(s).{% else %}This instance reads a shared database at {{ cve_db }}, read-only; it does not query the network.{% endif %}
  • Host fingerprinting (the Host tab) runs an nmap connect scan (-sT -sV, no OS detection, no raw packets) of an in-scope address, then matches each service's CPEs against the sources above. You can also enter a product or package version by hand.
